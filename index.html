Band Analysis Summary

Each band and each path are checked independently. Short-path predicted counts for Loop 2 are compared with short-path observed counts for Loop 2. Long-path predicted counts for Loop 3 are compared with long-path observed counts for Loop 3. The comparison can also be made with R2 for short-path and R2 for long-path. A blended R2 made by merging both paths will not be valid.

Q & A

Q. How does the model work?

A. Worked example. This example uses two directional loop antennas on 2026-05-05 at 17:00 UTC on 20m at end-points Brisbane <> Frankfurt.

Spot counts from each directional antenna are used to calculate a path dominance score and the observed direction, short-path or long-path. The model then tries to reproduce those antenna observations with an optimum combination of solar variables and coefficient multipliers.

The measured spot counts are in the Europe Bar Truth tab for 2026-05-05, 17:00 UTC, 20m:

Loop2_count = 202
Loop3_count = 53

path_dominance_score = (Loop2_count - Loop3_count) / (Loop2_count + Loop3_count)
path_dominance_score = (202 - 53) / (202 + 53)
path_dominance_score = 149 / 255
path_dominance_score = 0.584

Because Loop 2 has the higher spot count, the antenna evidence favours short-path propagation in this 30-minute bin.

The model then attempts to reproduce the antenna observations by multiplying calculated solar/path variables by optimised coefficients. This optimisation method is multiple regression. If the model agrees well with the antenna observations, the model may be useful. If it does not agree well, a model calibration process is needed.

The long-term aim is for a station without directional antennas to use the nearest validated model as an indication of likely long-path or likely short-path propagation.

About This Prototype

This first JavaScript port is intentionally narrow. It is designed to establish numerical trust against the Python reference before adding broader operator tools.

The simple model estimates path support from constant, dark_delta, greyline_delta, and endpoint_twilight. Coefficients are fitted separately for each band and each path. Weighted R2 uses spot count as the weight. SNR is not used.

bearing_difference values are degrees between a fixed antenna bearing and a calculated path bearing. Values can be high because an antenna may be pointing away from that path; 0 degrees is aligned, 90 degrees is broadside, and 180 degrees is opposite.
